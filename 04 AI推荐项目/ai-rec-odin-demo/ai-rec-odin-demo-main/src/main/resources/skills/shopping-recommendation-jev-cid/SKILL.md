# 个性化好物推荐·类目意图版

代码先加载技能并查询画像、行为。模型不选择工具，只在需要时决策一条召回查询。

第一轮只调用 `select_cid1`，返回「产品词｜品牌」，不要匹配一级或二级类目：

```json
{"name":"select_cid1","arguments":{"query":"羽毛球拍｜川崎"}}
```

- 只选择当前 `availableTools` 里的那一个工具。
- `query` 必须是两段，用中文或英文竖线分隔。产品词写具体商品，品牌写完整品牌或型号。
- 不要返回分数、理由或解释，也不要改写成类目名。

后续屏不读取左侧旁路兴趣画像。有模拟点击则用这些 SKU 做 i2i，不再请求模型；一个都没点则再调用 `select_cid1`，返回一条相关的「产品词｜品牌」。必须换产品词，品牌可以沿用，不要重复已用过的产品词，不要写成类目名。上一屏的点击不会继续当 i2i 种子。

商品卡片由服务端直接采用 Diviner 返回值。不要编造类目名称、商品属性或用户行为。

交互规则：

- 页面记录本屏曝光 SKU 和“模拟点击”SKU。
- 刷新下一屏时，把首屏 cid2、相关 cid2，以及最近 100 条 Session 曝光/点击事件一并交给工作流；召回只认本屏点击或无点击探索，不跟旁路兴趣度走。
- 一个都没点时，不得把曝光未点击解释成正向兴趣，也不能用曝光 SKU 或历史点击兜底做 i2i。
- 所有模拟曝光与点击都不得写入真实 AI Memory 或伪装成真实行为。
